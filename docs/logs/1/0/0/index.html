Change Log — 1.0.0

Permalink for version 1.0.0.

1.0.0 2026-07-07 · The first assembled release

The whole framework in one build, with the core features that used to ship as a separate extension folded into the plugin.

Added Talking to an agent

  • The /ai command in two modes: one-off questions, and a continued conversation that remembers the session.
  • Players and the console both use it, and a response countdown keeps a single player from queueing up overlapping requests.

Added Tools that respect permissions

  • Built-in tools for tokens, platforms, and models, each checking who is asking before it acts.
  • Extensions register their own tools the same way, so a tool from an extension is held to the same checks.

Added A staged tool workflow

  • Rather than sending every tool on every request, the agent narrows down by category, then by name, and only then receives full tool definitions.
  • Prompt caching is used where the AI platform supports it. Both keep token spend down.

Added Choice of storage

  • A local file database by default, or PostgreSQL, MongoDB, or the shared central server when several servers should see the same accounts and history.

Added Reusable prompts and automated testing

  • Prompts can be saved and re-run by id, either server-wide or as a player's own, and can be pinned to a fixed set of tools.
  • The /ai tester command replays saved prompts against a dedicated account and writes a report for each run.
