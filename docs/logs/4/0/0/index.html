Change Log — 4.0.0

Permalink for version 4.0.0.

4.0.0 Latest 2026-08-03 · The extension loader is gone

MCAgents no longer bundles the MCExtension loader. The plugin now carries nothing platform specific at all, which makes it simpler to install and simpler to build — but it changes how add-ons reach it.

Add-ons loaded by MCExtension will stop loading. The /mcaiextension command is gone and the plugin no longer loads extension jars itself. An add-on that relied on it has to run as an ordinary server plugin and register its tools through the plugin's own API instead. If you run PlayerTools or ServerTools, check for an updated release before upgrading.

Changed The MCExtension loader was removed

  • The bundled loader, its command, and its mcaiextension.admin permission are all gone. Nothing in the plugin loads other jars any more.
  • Add-ons still extend the agent the same way once they are running — they register tools through the plugin's API, which is unchanged. Only the mechanism that started them has been removed.

Changed One plugin class for every server

  • The loader was the only part of the plugin that needed to know which server it was running on. With it gone, nothing is platform specific: the plugin stays on the common server API and does its background work on its own threads rather than a server scheduler.
  • The universal jar therefore no longer detects anything at startup — it is simply correct everywhere. The per-server downloads remain, and now carry identical code, differing only in the descriptor inside them.

Note Nothing else changed

  • Commands, agents, tools, prompts, testing, and every storage backend behave exactly as they did in 3.1.0. There is no configuration change and nothing to migrate.
  • Building from source no longer needs credentials for a private package registry, so a fresh checkout builds on its own.
