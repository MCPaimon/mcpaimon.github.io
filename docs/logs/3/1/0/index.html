Change Log — 3.1.0

Permalink for version 3.1.0.

3.1.0 2026-08-03 · One jar for every server

Installing the plugin used to mean picking the download that matched your server software, and picking wrong failed at startup. There is now a single build that works on all three.

Added A universal build

  • The new MCAgents jar detects whether it is running on SpigotMC, PaperMC, or FoliaMC when the server starts, then installs the scheduling and extension behaviour that server needs.
  • The same file works on every supported server, so there is nothing to match up and nothing to get wrong.
  • Folia is detected before Paper, because a Folia server also answers to the Paper check. Anything that identifies as neither is treated as Spigot, which is the safe default for a fork.

Note The single-server builds remain

  • MCAgentsSpigotMC, MCAgentsPaperMC, and MCAgentsFoliaMC are still produced for anyone who prefers a smaller artifact aimed at one server.
  • Nothing about them changes, and there is no need to switch.

Changed Supporting a new server got cheaper

  • What differs between servers is now a single small piece rather than a whole startup sequence, so adding a platform means writing that piece instead of another copy of the plugin.
