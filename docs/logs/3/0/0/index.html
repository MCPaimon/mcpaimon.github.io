Change Log — 3.0.0

Permalink for version 3.0.0.

3.0.0 2026-08-03 · A smaller published surface

A tidy-up of what the project publishes, and the end of a long-standing duplication between the three server builds.

The three server builds are no longer published as libraries. mcagents-spigotmc, mcagents-papermc, and mcagents-foliamc are gone from the package registry. They were never meant to be depended on — they are downloads. Anything that listed one as a dependency should depend on mcagents-bukkit instead. Installing the plugin is unaffected.

Changed Only the libraries are published

  • The four library pieces — mcagents-api, mcagents-tools, mcagents-common, and mcagents-bukkit — are what other projects build against, so they are what gets published.
  • The runnable server builds are downloads rather than dependencies, and publishing them exposed their bundled internals as an artifact.

Changed One startup sequence, not three

  • Each server build carried its own copy of the same startup code, and the copies had already drifted apart from one another.
  • They now share one sequence and keep only what genuinely differs, which removed over five hundred lines of duplication and the class of bug where a fix reaches one server but not the others.

Added MySQL became selectable

  • A MySQL backend had been written but was never reachable from the configuration file.
  • Set database.type to mysql and fill in the database.mysql section, which the shipped config.yml now documents alongside the others.
  • MariaDB is accepted under the same setting.
