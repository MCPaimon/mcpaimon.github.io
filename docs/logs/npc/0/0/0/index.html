Change Log — 0.0.0

Permalink for MCAgentsNPC version 0.0.0.

0.0.0 2026-08-05 · NPCs that understand what you ask for

The first release of MCAgentsNPC, a new plugin in the MCPaimon family. It puts NPCs on your server that gather, farm, fight, keep watch, and follow you — and that take their instructions in plain language rather than from a menu.

Added NPCs with six behaviours

  • Spawn an NPC where you stand, name it, and give it one of six jobs: gathering, farming, fighting, observing, following, or standing by.
  • A gathering NPC breaks only the blocks an operator has listed and keeps what they drop, so nothing you did not permit is ever dug up and nothing ends up scattered on the floor.
  • A farming NPC harvests ripe crops and replants them. The field it works stays a field — it never leaves you with cleared ground.
  • A fighting NPC attacks hostile mobs only. Players, animals, and villagers are never targets, and that is fixed in the behaviour rather than left as a setting.
  • An observing NPC changes nothing and reports only when what it can see has changed, so a lookout is useful without becoming noise.
  • Each player may keep three NPCs by default, and they are removed when their owner logs out.

Added Instructions in your own words

  • Describe what you want — "there is iron in the cave below, go get it" — and the agent picks the behaviour that fits and answers in one line.
  • Before asking anything, the NPC reports what it can actually see: who is nearby, what creatures are around, what it is standing on, and whether it is day or night. The answer is about your situation rather than a generic one.
  • A question that is not an order is answered without interrupting whatever the NPC was doing.
  • Naming a behaviour directly still works, costs nothing, and needs no AI at all.

Added Short-term memory that forgets on purpose

  • An NPC remembers your conversation, so your next message can be a follow-up: "keep at it until you have enough" works.
  • What it keeps is a summary of each exchange, never the words you typed. Remembered turns are replayed into every later request, so anything stored word-for-word would be paid for again on every message that followed it.
  • Five minutes without a new task and the conversation is dropped whole. The window is configurable, and asking to see the memory does not extend it — only a new instruction does.
  • Nothing is written to disk or to a database. Short-term context lives in memory for as long as the server runs, and a restart forgets all of it.
  • A command shows exactly what an NPC is about to replay, and another clears it. Memory that summarises and then deletes itself is hard to trust without a way to look at it.

Added An optional MCAgents integration

  • MCAgentsNPC is a standalone plugin, not an extension. It installs and runs on its own.
  • When MCAgents is installed alongside it, MCAgentsNPC finds it on the running server and binds to it there rather than being built against it. That is why it loads cleanly on a server without MCAgents, and on one whose MCAgents is a different version.
  • If the binding fails, the integration switches off, not the plugin. One clear line goes to the log, NPCs still spawn, and every behaviour still runs — you set them by name instead of by sentence.
  • The plugin holds no API key of its own. Every request is made by MCAgents on the asking account's key, so a player's instruction spends that player's key exactly as a direct question to MCAgents would.
  • It works the other way too: two tools are handed to MCAgents so a player already talking to an agent can list and retask their NPCs without touching the NPC command. Both are limited to that player's own NPCs.

Added One command, one node per action

  • Spawning, removing, listing, setting a behaviour, giving a task, collecting what was gathered, inspecting memory, and reloading each carry their own permission node.
  • Everything defaults to being open to players, because there is nothing shared to protect: a task spends the player's own key. Only reloading is restricted to operators, since it removes every NPC on the server.
  • Ownership is separate from permission: a player may command their own NPCs and nobody else's, whatever nodes they hold, while operators may command any.
  • The help menu and tab completion list only the subcommands you actually hold, so a withheld command never appears as a dead end.

Note What to expect from an NPC

  • NPCs move by stepping towards a goal rather than by pathfinding. One climbs a single block and drops a few, and gives up on anything it cannot reach that way. Excellent in a field, a quarry, or a cleared cave; poor in a maze.
  • An NPC that strays too far from where its behaviour started walks back, so it works the area you pointed it at instead of drifting across the map.
  • Player damage to an NPC is cancelled — they cannot defend themselves against you, and a misclick would cost you the helper and everything it carried. Creepers, falls, and lava still count, and an NPC that dies drops what it was carrying.
  • The plugin ships disabled. Dropping the jar into a server changes nothing until an operator sets enable: true and restarts.

Note Installing

  • The universal MCAgentsNPC jar detects whether it is running on PaperMC, SpigotMC, or Folia at startup and installs the matching scheduling support, so one file works on any of them.
  • Three per-server builds are published alongside it for anyone who wants a smaller artifact targeted at one platform.
  • There is no database to set up and no key to register. The plugin stores nothing.
