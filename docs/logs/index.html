5.1.0 Latest 2026-08-04 · Housekeeping under the hood

A maintenance release. The plugin's core entry point was reorganised internally so it is easier to work on; nothing you configure, run, or build against has changed.

Changed The plugin's core was reorganised

  • One class had grown to carry nearly everything the plugin does at once: encrypting stored keys, resolving which provider and account a request belongs to, driving the multi-step reasoning loop that answers a prompt, and holding the registered tools, categories, and saved prompts.
  • Each of those is now a separate, focused part with a single job. The entry point keeps its role as the one door into the plugin and hands each request on to the part that owns it.
  • Two pieces of repeated logic inside the reasoning loop were merged into one, so a fix there now applies everywhere instead of needing to be made twice.
  • The practical effect is on maintenance rather than behaviour: a bug in one area is now isolated to one small file, and new capabilities have an obvious place to go.

Note Nothing to do when upgrading

  • There is no configuration change and nothing to migrate. Drop the new build in place of 5.0.0 and carry on.
  • Commands, permissions, agents, tools, saved prompts, testing, and every storage backend behave exactly as they did in 5.0.0.
  • Add-ons do not need rebuilding. The plugin's public interface is unchanged — every method an add-on calls is still there, with the same name and the same arguments.
  • The downloads are unchanged too: the universal MCAgents jar still detects your server at startup, and the three per-server builds are still published alongside it.
